# Notebooks

- colab_feasibility_pilot.ipynb — development notebook for the Colab capacity check, Goldset task verification, model load, and completed feasibility/refinement pilots. These records are development data and are excluded from final evaluation.
- colab_final_evaluation.ipynb — runs the frozen 30-record public Goldset comparison with one fixed Qwen2.5-Coder-7B-Instruct snapshot, verifies the task oracles, compares retrieval off/on, summarizes paired outcomes, and downloads the JSON evidence archive.
